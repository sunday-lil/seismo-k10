# 追光台（solar）

赛道五【新兴产业】· 行空板 K10 双轴追光 + 净发电量对比。

## 一句话

同一光源、同一段日照，比较 **固定 30° / 连续追光 / 死区追光** 三种策略**扣掉自身耗电后**的净发电量。

## 结论

| 组别 | 发电量 | 耗电 | 净产出 | 相对固定 |
|---|---:|---:|---:|---:|
| A 固定 30° | 1433 mWh | 0 | 1433 | — |
| B 连续追光 | 2116 mWh | 480 | 1636 | +14.1% |
| C 死区追光 | 2109 mWh | 64 | **2045** | **+42.7%** |

追光收益不在“转得快”，在“少转”。
