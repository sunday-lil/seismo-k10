# v1.1 功能说明：给 K10 加一个遥测端

主帖（v1.0）解决的是“能不能在教室里做一次可重复的地震”。
v1.1 解决另一个问题：**做实验的时候，人不该被绑在板子前面看屏幕。**

## 改了什么

| 项 | v1.0 普通版 | v1.1 遥测版 |
|---|---|---|
| 看数据 | K10 屏幕 | 手机 / 电脑浏览器 |
| 触发记录 | 按 A 键 | 按 A 键，或网页点“记录一次” |
| 网络 | 不需要 | WiFi（STA，连不上回落热点） |
| 数据 | TF 卡 / 串口 | TF 卡，同时 HTTP 可取实时快照 |
| 代码量 | 570 行 | 550 行（多 WiFi/HTTP，屏幕简化） |

## 为什么用 Web，不用蓝牙

| 方案 | 优点 | 缺点 |
|---|---|---|
| Web | 零安装、任何手机浏览器能开、调试方便 | 需要同一网络 |
| BLE | 不用网络 | 安卓要写 GATT，iOS 兼容麻烦 |
| 串口转 WiFi 模块 | 稳 | 多一块硬件，破坏“零外接” |

K10 自带 WiFi，Web 是最省的路线。APK 只是壳，负责连接、全屏、常亮、断线重连。

## 技术要点

**1. HTTP 不能抢采样**
主循环 200 Hz 采样，每 20 ms 服务一次 HTTP。采样用绝对时间戳推进：

```cpp
g_nextUs += 1000000UL / FS_HZ;   // 不随 HTTP 处理漂移
```

**2. 记录时也不停服务**
记录阶段每 50 ms 服务一次，`/api/now` 返回 `RECORDING`，手机端知道要等。

**3. 快照不加锁**
HTTP 读 `waveWin[]` 快照，采样侧只做 memmove。最坏情况是某一帧波形错位，不影响记录精度。

**4. APK 自动找板子**
依次尝试：上次地址 → `seismo.local`（mDNS）→ `192.168.4.1`（热点）。
全部失败显示提示页，列出试过的地址，点一下改。

## 踩过的坑

**配网后 App 灰屏**
K10 从热点模式切到路由器模式，IP 从 `192.168.4.1` 变成路由器分配的地址，App 还记着旧地址。
解决：加 mDNS + 自动回退 + 失败提示页。

**中文路径编译不了 APK**
AGP 报 `non-ASCII characters`。解决：同步到 `C:\tools\seismo_android` 再编译。

**Gradle 脚本在 MSYS 里被 `;` 截断**
改成直接 `java -classpath gradle-launcher-*.jar`。
