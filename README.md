## 三个作品共同的方法

**把看不见的过程变成可测量的量。**

| | 问题 | 可测量的量 |
|---|---|---|
| 震感捕手 | 桌面上的震动如何随距离衰减 | 峰值加速度 PGA |
| 遥测版 | 实验时人不必守在板子前 | 实时波形（HTTP） |
| 追光台 | 追光到底能多收多少电 | 净能量 = 发电 − 追光耗电 |
| 闪传节点 | 跨系统传文件不装 App | 传输速率、兼容性矩阵 |
