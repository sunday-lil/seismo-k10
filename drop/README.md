# 闪传节点（K10）

一块行空板 K10 开热点，Windows / macOS / 安卓 / iOS 用**浏览器**打开同一个地址，就能互传文件。不装 App，不需要路由器。

## 怎么用

1. 烧 `02_代码/K10端/main_drop.cpp`
2. 手机/电脑连 WiFi `K10-Drop`，密码 `12345678`
3. 浏览器打开 **http://192.168.4.1**
4. 拖文件进去 → 别人点「下载」

## 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/` | 网页 |
| GET | `/list` | 文件列表 JSON |
| GET | `/dl?f=名字` | 下载 |
| POST | `/up` | multipart 上传（字段 `file`） |
| GET | `/rm?f=名字` | 删除 |

文件存在 TF 卡根目录 `S:/`。

## 已知限制

- 单连接为主，多人同时传会排队（`WebServer` 阻塞式）
- 理论速率 150–250 KB/s（WiFi AP + SD 写入）
- 文件名会被过滤成字母数字下划线，避免路径穿越
- 没有加密，内网使用
