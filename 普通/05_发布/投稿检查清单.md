## 二、投稿前必须做的 5 件事

### ⬜ 1. 补实物照片（2 张）

- **照片 1 · 装置全景**：两张课桌拼接、左端落球管与钢片、右端 K10、桌边卷尺刻度；必须能看清“0 m”起点和至少 2 m 刻度。
- **照片 2 · K10 特写**：屏幕显示波形与 PGA，旁边放一颗钢球作比例参照。
- 拍摄：白天靠窗、侧逆光，手机横拍 4:3，桌面清空，背景用纯色板。

### ⬜ 2. 拍演示视频（30 秒）

按文档 2.4 的分镜拍；波形跳动用 120 fps 慢动作；屏幕反光时用白纸柔光。传 B 站/腾讯视频后把链接填进帖子。

### ⬜ 3. 换成实测数据

1. 用 K10（`main.cpp`）按 `03_数据/实测记录表.xlsx` 的流程采数据；没插卡时用 `serial_capture.py` 从串口抓；
2. 把 CSV 放进 `03_数据/实测/`（可以分子文件夹）；
3. 运行：

```bash
python 02_代码/分析端/analyze.py
python 02_代码/分析端/build_doc.py
```

4. 打开文档，确认第 2 页的“数据状态”从“示例数据”变成“实测数据”，第 3 章图表已更新。

> 判断脚本用的是哪套数据：看 `analyze.py` 启动时打印的“数据目录”。有实测文件就用实测，没有才退回示例。

### ⬜ 4. 填作者信息

文档封面底部：作者 / 学校 / 指导教师；帖子开头也加一句学校与年级。

### ⬜ 5. 核对数字与结论

- 拟合的 n、R²、盲测误差是否与你的数据一致；
- “1.4 m 与 1.6 m 两档均值接近”这句话是脚本按数据自动生成的，换成实测后请确认它仍然成立（不成立就把那句话删掉）；
- 结论里“斜撑使 PGA 下降约 60%”之类的百分比同样来自数据，会自动更新。

## 四、答辩/说课可能被问到的 6 个问题

1. **为什么不用走时差定位？** → 桌面 2 m、波速千米每秒，走时 < 1 ms，而采样间隔 5 ms，测不准；改用振幅反演，并说明这是“替代观测量”。
2. **200 Hz 够吗？** → 对 1–10 Hz 的结构响应足够；对冲击峰值欠采样，PGA 可能低估几个百分点，已在局限中写明。
3. **怎么保证每次激励一样？** → 定高落球管 + 钢片 + 固定落点；重复 5 次看变异系数（3%–12%）。
4. **盲测误差 8% 可信吗？** → 示例数据偏理想；实测通常在 10%–20%，文档已提示按实测更新，并给出误差随距离增大的物理解释。
5. **和真实地震有什么关系？** → 传播、衰减、偏振、共振四个机制同构；但尺度、边界、相似准则不同，只做定性/半定量外推。
6. **学生到底学到了什么？** → 控制变量是被坏数据“逼”出来的；模型的价值在于能对没见过的数据做预测；预测错了要解释而不是调参。
