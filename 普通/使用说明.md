# 怎么用（3 分钟版）

这套东西分两条路，**先看你手上有没有行空板 K10**。

---

## 路线 A：手上还没有板子 —— 先看成品、跑通流程（5 分钟）

### 1. 先看两份成品

- 直接双击打开 `01_作品文档/震感捕手_科学教育实践案例.pdf`（不用装 Word）
- 要改内容就开同名的 `.docx`

看完你就知道这个案例长什么样、缺什么。

### 2. 跑一遍“数据 → 图表 → 文档”的自动流程

双击根目录的 **`一键运行.bat`**。

它会做三件事：

1. 检查 Python 依赖（缺了自动装，第一次要等几分钟）
2. 读 `03_数据/示例数据/` 里的 89 个 CSV，算出 PGA、拟合曲线、盲测误差
3. 重新生成 `01_作品文档/…docx` 和 `04_图片/` 里的所有图

跑完打开 docx，你会发现里面的数字、表格、图都还在——因为它们是从数据自动生成的。

> 没有 Python？去 python.org 装 3.10 以上，安装时勾选 **Add Python to PATH**。

### 3. 想单独跑某一步

```bat
python 02_代码\分析端\analyze.py      :: 只算数据、出图
python 02_代码\分析端\build_doc.py    :: 只重新生成 Word
python 02_代码\分析端\make_figures.py :: 只重画示意图/封面/界面图
```

## 路线 B：手上有 K10 —— 上机实测（约 40 分钟）

> **只用 Mind+？** 先看 [Mind+刷入说明](Mind+刷入说明.md)：上传模式的代码视图就是 C++，直接粘 `main.cpp`；如果代码区是灰色只读，就走下面的 Arduino 路线。

### 第 1 步：装 Arduino 环境（15 分钟，只装一次）

1. 装 [Arduino IDE 2.x](https://www.arduino.cc/en/software)
2. 打开 **文件 → 首选项 → 附加开发板管理器网址**，粘贴：

   ```
   https://downloadcd.dfrobot.com.cn/UNIHIKER/package_unihiker_index.json
   ```

3. **工具 → 开发板 → 开发板管理器**，搜索 `unihiker`，安装 **UNIHIKER K10**
4. 插上 K10，**工具 → 开发板** 选 `UNIHIKER K10`，**工具 → 端口** 选新出现的 COM 口

> 装 BSP 报错多半是网络问题，关掉杀毒/防火墙重试；实在不行用 PlatformIO 路线（见文末）。

### 第 2 步：改参数、上传（5 分钟）

1. 用 Arduino IDE 打开 `02_代码/K10端/normal/v0/main.cpp`
2. 只改最上面这四行：

   ```cpp
   #define EXP_ID    "E1"     // 实验一填 E1，实验二填 E2，实验三填 E3
   #define DIST_M    0.60f    // 这次测点离震源几米，卷尺量
   #define TRIAL_NO  1        // 第几次重复
   #define NOTE_TXT  "wood"   // 木桌写 wood，瓷砖写 tile
   ```

3. 点左上角 **上传**（→ 图标），等出现 `Done uploading`

### 第 3 步：摆装置（10 分钟）

照着 `04_图片/fig6_装置示意图.png` 摆：

- 两张课桌拼成 ≥ 2 m，桌腿垫泡沫
- 桌子一端立纸筒（高 50 cm），下面贴钢片，这是 **0 m**
- 卷尺沿桌边拉直，每 10 cm 贴一条胶带
- K10 **平放**在测点上，屏幕朝自己，用笔记下外框位置

### 第 4 步：记录（每次 5 秒）

1. 按 **RST**，屏幕出现 `MONITOR` 和三轴波形
2. 静置 10 秒，PGA 应该小于 0.005 g（不静就说明桌子在抖）
3. 按 **A 键** → 屏幕显示 `WAIT TRIGGER`
4. 让钢球从纸筒口自由落下
5. 灯变红 → 约 4 秒后屏幕显示 `RECORD DONE`，记下 PGA
6. 按 **B 键** 回到待机，改距离/次数，重复

**每个距离做 5 次**，中间不要挪桌子。

### 第 5 步：把数据弄到电脑（2 分钟）

**方法一（推荐）：拔 TF 卡**

- 断电 → 拔卡 → 读卡器插电脑
- 卡里会有 `E1_d060_t1.csv` 这样的文件
- 全部复制到 `03_数据/实测/`（可以建子文件夹）

**方法二：没插卡 / 写卡失败**

- 保持 USB 连接，关掉 Arduino 的串口监视器
- 双击 `02_代码/分析端/serial_capture.py` 所在的命令行，运行：

  ```bat
  python 02_代码\分析端\serial_capture.py --port COM7
  ```

  （COM7 换成你的端口；只插了一块板子时可以省略 `--port`）
- 然后按 A 键记录一次，脚本会自动把数据存进 `03_数据/实测/`

### 第 6 步：出文档（1 分钟）

数据放好后，再双击 **`一键运行.bat`**。

它会优先用 `03_数据/实测/` 里的真实数据（没有才退回示例数据），重算全部图表，并刷新 Word 文档。

打开 docx，翻到第 3 章，确认：

- 第 2 页的“数据状态”变成了 **实测数据**
- 表里的 PGA、拟合的 n、盲测误差都换成了你的数

## 路线 C：不想装 Arduino IDE —— PlatformIO

1. VS Code 装 PlatformIO 插件
2. 新建工程，把 `02_代码/K10端/platformio.ini` 覆盖过去
3. `main.cpp` 放进 `src/`
4. 点 Upload

`platformio.ini` 里已经写好板卡、框架和 USB CDC 参数。

## 三个最容易踩的坑

1. **`unihiker_k10.h: No such file`** → BSP 没装好，回第 1 步重装。
2. **PGA 一直是 0.000** → 看静置时 Z 轴读数：约 1000 是对的；约 9.8 说明你的 BSP 返回 m/s²，把 `main.cpp` 里的 `ACC_TO_G` 改成 `1.0f / 9.80665f`。
3. **没有生成 CSV** → 卡不是 FAT32，或 `S:/` 没挂载。程序会自动改走串口，用第 5 步的方法二接住就行。

## 文件都在哪

```
01_作品文档/     ← 成品 docx / pdf
02_代码/K10端/   ← main.cpp（上传到板子）
02_代码/分析端/  ← analyze.py / serial_capture.py / 生成文档的脚本
03_数据/         ← 示例数据、实测数据、记录表
04_图片/         ← 所有插图
05_发布/         ← 发帖正文、检查清单、源码压缩包
```
