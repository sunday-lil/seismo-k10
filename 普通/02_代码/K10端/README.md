# K10 端代码

两个独立版本，互不影响，按需选一个烧。

```
K10端/
├── normal/          普通版：脱机记录（比赛提交版）
│   ├── README.md
│   └── v0/
│       ├── main.cpp
│       └── platformio.ini
│
（遥测版不在这个目录里，在仓库根目录的 web/）
web/                  遥测版：WiFi + Web 服务器 + 手机 App（v1.1）
├── README.md
├── 02_代码/v0/main_web.cpp
├── 02_代码/android/          APK 工程
├── 02_代码/build_apk.bat     一键编译
└── 02_代码/震感捕手_遥测版.apk
```

## 两个版本的区别

| | normal（普通版） | web（遥测版） |
|---|---|---|
| 使用方式 | 板子独立跑，屏幕看结果 | 手机/电脑浏览器看实时波形 |
| 网络 | 不需要 | 需要 WiFi |
| 记录 | 按 A 键，存 TF 卡 / 串口 | 按 A 键或网页按钮，存 TF 卡 |
| 代码量 | 约 570 行 | 约 550 行（多 WiFi/HTTP） |
| 适用场景 | 课堂实验、比赛演示 | 演示、调试、多设备组网 |
| 提交状态 | 已发布（主帖） | v1.1 扩展，可单独发帖 |

## 版本号约定

`v0` 是当前稳定版。以后改动新建 `v1/`、`v2/`，**保留旧版本**，方便对比和回滚。
每个版本目录里放一份完整可编译的工程，不要跨版本共享文件。

## 烧录

两个版本都用 Mind+ 代码模式粘贴：

- 普通版：`normal/v0/main.cpp`
- 遥测版：`../../../web/02_代码/v0/main_web.cpp`

板型选 **行空板 K10**，编译上传。
