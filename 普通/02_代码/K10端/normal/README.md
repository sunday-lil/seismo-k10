# 普通版（v0）：脱机记录

比赛主帖用的就是这个版本。不联网，按 A 键记录一次，数据写 TF 卡或从串口输出，屏幕直接显示峰值、主频、时长。

## 文件

- `main.cpp`：Arduino C++ 主程序（约 570 行，中文注释）
- `platformio.ini`：PlatformIO 工程配置（用 Arduino IDE / Mind+ 的话不需要）

## 按键

| 键 | 待机时 | 记录中 |
|---|---|---|
| A | 开始记录（先校准基线） | — |
| B | — | 取消，回待机 |

## 数据输出

优先写 TF 卡，路径 `S:/E1_d060_t1.csv`；没卡或挂载失败时同一段 CSV 从 USB 串口整块输出（用 `../../分析端/serial_capture.py` 接）。

CSV 头：

```
# device=UNIHIKER K10
# exp=E1
# dist_m=0.600
# trial=1
# note=wood
# fs=200.0
# unit=mg
# trig_idx=200
# pga_g=0.3120
# f_hz=28.40
# dur_ms=186.0
t_ms,ax,ay,az
```

`t_ms=0` 是触发点，触发前 1 s、触发后 4 s，共 1000 点。

## 参数（改文件顶部宏）

| 宏 | 默认 | 说明 |
|---|---|---|
| `EXP_ID` | `"E1"` | 实验编号，写进文件名和 CSV 头 |
| `DIST_M` | `0.60f` | 测点距离（米） |
| `TRIAL_NO` | `1` | 第几次 |
| `FS_HZ` | `200` | 采样率 |
| `PRE_S` / `POST_S` | `1.0` / `4.0` | 触发前/后记录时长 |
| `TRIG_G` | `0.05f` | 触发阈值（g） |
| `ALARM_G` | `0.25f` | 报警阈值，屏幕变红 |
